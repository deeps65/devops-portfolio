# Deepanshu — DevOps Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. No build step or package installation is required.

## Preview locally

Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.


## Deploy

This is a static site. You can publish the folder with GitHub Pages, Netlify, Cloudflare Pages or any static web host. Upload the contents of this folder as the site root.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, contact links and subtle reveal effects
- `config.js` — public contact details

## Why Use Local LLMs?

Running LLMs locally offers key advantages:

- **Privacy**: Process sensitive data without external exposure; no GDPR concerns
- **Cost**: No API fees—no per-request costs that accumulate at scale
- **Customization**: Fine-tune on domain knowledge and add custom safety guards
- **Flexibility**: Deploy anywhere, even air-gapped systems; no third-party dependencies

**TL;DR**: Local LLMs give you privacy, customization, and control without API costs.
